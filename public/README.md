# TaskFlow — Modern Minimalist Task Manager

**Demo en vivo:** [https://taskflow-minimalist-manager.web.app](https://taskflow-minimalist-manager.web.app)

# Gestor de Tareas (Entregable 2)

Aplicación web de gestión de tareas con un diseño premium y minimalista, creada utilizando exclusivamente **HTML5, CSS3 y JavaScript vanilla**.

## Funcionalidades
- **Pantalla de Bienvenida:** Animación inicial (splash screen) elegante con un logo dinámico.
- **Crear Tareas:** Permite agregar nuevas tareas definiendo su estado inicial.
- **Visualizar:** Interfaz limpia con lista de tareas persistente gracias al uso de LocalStorage.
- **Actualizar:** Capacidad para editar el título de la tarea o alternar rápidamente su estado (Pendiente, En Proceso, Completada).
- **Eliminar:** Borrado de tareas con actualización instantánea de las estadísticas.
- **Filtros Dinámicos:** Navegación por categorías para organizar visualmente las tareas según su progreso.

## Uso de Inteligencia Artificial
Durante el desarrollo y optimización de esta entrega, se empleó **Google AI Studio (Gemini)** como asistente de programación para refactorizar la arquitectura y elevar la calidad del diseño UI/UX.

**Prompts principales utilizados en el proceso:**
1. *"Por favor, ayúdame a simplificar la estructura de este proyecto para utilizar únicamente tres archivos base (index.html, styles.css y script.js) sin depender de frameworks externos, garantizando que la lógica CRUD siga funcionando correctamente."*
2. *"Mejora la interfaz de usuario implementando un diseño premium y minimalista. Utiliza CSS puro para añadir efectos modernos como 'glassmorphism', una paleta de colores sofisticada y transiciones suaves, asegurando un acabado profesional."*
3. *"Tengo un fragmento de código CSS que genera un loader animado. ¿Podrías integrarlo de forma armónica como el logo principal en la cabecera de la aplicación, ajustando su tamaño sin perder la calidad de la animación?"*
4. *"Finalmente, me gustaría implementar una pantalla de bienvenida (splash screen) con un fondo oscuro que muestre esta misma animación a gran escala durante un breve instante antes de revelar la interfaz principal. ¿Puedes agregar la lógica necesaria para lograr este efecto?"*

**Verificación:** 
Todo el código generado o adaptado por la IA fue analizado y testeado manualmente en el navegador para confirmar que las animaciones sean fluidas, el diseño sea responsivo y la persistencia de datos (LocalStorage) funcione sin errores.
