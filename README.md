# TaskFlow — Modern Minimalist Task Manager

**Demo en vivo:** [https://taskflow-minimalist-manager.web.app](https://taskflow-minimalist-manager.web.app)

## Estructura del Proyecto

```text
TaskFlow/
├── public/
│   ├── index.html    # Interfaz principal
│   ├── styles.css    # Estilos (Glassmorphism & Animaciones)
│   ├── script.js    # Lógica CRUD y Persistencia
│   └── favicon.svg   # Icono de la aplicación
├── firebase.json     # Configuración de Firebase Hosting
└── .firebaserc       # Identificación del proyecto en Firebase
```

## Prompts utilizados

Durante el desarrollo se utilizaron los siguientes prompts con **Gemini**:

1. *"Simplificar la estructura del proyecto para utilizar únicamente tres archivos base (index.html, styles.css y script.js) sin frameworks externos."*
2. *"Implementar un diseño premium y minimalista con CSS puro, efectos 'glassmorphism' y transiciones suaves."*
3. *"Integrar un loader animado como logo principal en la cabecera ajustando su tamaño."*
4. *"Implementar una pantalla de bienvenida (splash screen) con fondo oscuro y la animación a gran escala."*
